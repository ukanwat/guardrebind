\section{Target Rebinding}
\label{sec:attack}

\paragraph{Hypothesis.}
The instruction/query/document convention has no parser: it is plain text interpolated by the developer.
A second well-formed query--document pair inside the content is, to the model, indistinguishable from the developer's, so the model grades the document of the last complete pair it sees.
On this account the guard is not persuaded to answer ``safe''; it answers the same kind of question about a different document.
For Shieldstral a complete grading task is a query and a document; guards whose grading task also includes instructions need those forged too (\cref{sec:request-unit}).
The hypothesis predicts three things, which this section tests in turn: only a complete forged pair should work (\cref{sec:core}); the verdict should follow the harm of the decoy (\cref{sec:groundtruth}); and the effect should not depend on recency, one label syntax, the policy wording or exact knowledge of the deployment (\cref{sec:robustness}).
The evidence in \cref{sec:core,sec:groundtruth,sec:robustness} is behavioural; \cref{sec:binding} adds activation-level analyses.

\paragraph{Setup.}
The ablation panel, the borderline-decoy comparison and the position, label-syntax and policy variations follow a protocol frozen before the run (\cref{app:protocol}).
Results marked \emph{exploratory} were added after the confirmatory run: the wider set of 100 requests, the three-decoy comparison, the softened query, the forged-query variants and the forged-verdict controls.
The corpus is AdvBench~\citep{zou2023universal} rows 200--299, which no exploratory run touched; 75 of the 100 requests are flagged ($>0.9$) with no attack under the policy of \cref{fig:anatomy}; these screened requests form the denominator. % src: PROTOCOL.md; results/confirm_log.txt
Exact payload strings are in \cref{app:payloads}.

The attack appends a forged \texttt{<Query>} (the deployment's own safety question) and a forged \texttt{<Document>} holding a benign decoy sentence (\cref{fig:anatomy}).
It clears all 75 screened requests ($100\%$\ci{95\%}{100\%}, \cref{tab:ablation}): the median score falls from $0.986$ to $0.016$ and the highest attacked score is $0.469$ (\cref{fig:scores}a); at the stricter threshold $\tau=0.1$ it still clears $84\%$ (\cref{tab:sens-tau}). % src: results/confirm_shieldstral.csv; results/sensitivity.md
In an exploratory run on a wider set of 100 flagged AdvBench requests, which includes these 75, it clears 100 of 100 ($100\%$\ci{96\%}{100\%}). % src: results/hundred_log.txt, results/confirm_hundred.csv
These are AdvBench requests flagged above $0.9$; on the broader six-source test set of \cref{sec:benchmark}, with the deployment screen of $0.5$ and decoys and queries drawn from pools, the same pair clears $70.9\%$ (\cref{tab:per-family}). % src: results/bench/v2/bypass.csv shieldstral angle query_doc

The factorial panel in \cref{tab:ablation} holds one fixed sentence wherever an instruction appears, so wording cannot be confused with structure.
An instruction alone clears $0\%$, whether as a bare sentence, a ``Note:'' or a forged \texttt{<Instruct>} field.
A forged document with no query clears $9\%$.
A forged query and document clear $100\%$, and adding a forged instruction in front of them lowers this to $92\%$.
The pair, not any imperative text and not an extra document, carries the attack.

\subsection{The guard grades the decoy}
\label{sec:groundtruth}

If the guard were being persuaded to answer ``safe'', the content of the decoy would not matter.
In an exploratory comparison that holds the attack fixed and varies only the decoy, a \emph{benign} decoy (\emph{standalone score}, the guard's score on the decoy alone, $0.00$) clears $100\%$\ci{91\%}{100\%}, a \emph{borderline} decoy ($0.03$) clears $33\%$\ci{21\%}{49\%}, and a \emph{harmful} decoy, one the guard flags on its own ($\approx\!1.0$), clears $0\%$\ci{0\%}{9\%} ($n=39$, \cref{fig:scores}b). % src: results/groundtruth_log.txt, results/confirm_groundtruth.csv
The binding is not complete: with the borderline decoy the attacked median is $0.71$, far above the decoy's own $0.03$, so the original request still raises the score when the decoy is not clearly benign. % src: results/groundtruth_log.txt (attack median 0.7058)
The pre-registered ``harmful decoy'' of the confirmatory panel is this borderline decoy and clears 29--35\% (\cref{app:protocol}). % src: results/confirm_log.txt [groundtruth]

The forged query works by opening a new pair, not by softening the check.
In an exploratory control, forging a softened query (``is this a poem?'') while leaving the harmful request as the judged document, with no benign decoy anywhere, clears $0$--$9\%$ across five variants ($n=45$). % src: results/soften_log.txt, results/confirm_soften.csv
The working attack needs a benign decoy, and the harmful text survives, approved, at the top of the message.

\paragraph{Forged verdicts versus a forged task.}
\label{sec:verdict-vs-task}
Earlier and concurrent attacks on judges forge a verdict or an authority claim about the content, not a new task~\citep{mccauley2025hat,li2026same}.
In an exploratory control, on 200 harmful test items that Shieldstral flags alone, we append one of four such forgeries to the request: a plain-text statement that it was assessed as safe, a JSON moderation record marking it unflagged, a note that the safety team approved it, and a claimed earlier guard output of ``no''.
They clear $19\%$\ci{14\%}{25\%}, $6\%$\ci{3\%}{10\%}, $7\%$\ci{4\%}{11\%} and $6\%$\ci{3\%}{10\%}, against $96\%$\ci{92\%}{98\%} for the forged pair on the same items. % src: results/fix/forgery_controls_base.json (verdict_plain 38/200, verdict_json 11/200, authority 13/200, prior_verdict 11/200, task 192/200)
A split payload puts the first half of the request in the content and the second half in the forged document, so the decoy is itself part of the harm; it clears $9\%$\ci{5\%}{13\%}. % src: forgery_controls_base.json split_payload 17/200
A forged task, not a forged verdict, is what moves the guard.

\Cref{tab:robustness} varies one factor at a time around the core attack.
\emph{Position:} appending the pair clears $100\%$, prepending the identical pair clears $15\%$, while inert filler placed last clears $0\%$ (\cref{tab:ablation}); the effect needs the forged pair to be the last pair, not merely later text.
\emph{Syntax:} every label style clears $83$--$100\%$ and the same words without labels clear $0\%$, so the labelled structure is necessary but no single syntax is.
\emph{Query knowledge} (exploratory): the forged query must look like a safety question but need not match the deployment's: paraphrases and topical variants clear $100\%$, a generic query $89\%$, an unrelated query $9\%$, and a blind attacker who stacks five guesses, none of them the deployment's query, clears $100\%$. % src: results/supp_log.txt [A]
\emph{Policy:} across eight policy phrasings, each with a matched forged query, the median bypass is $99\%$ (range $87$--$100\%$). % src: results/confirm_log.txt [policy]
The attack therefore needs no white-box access and little knowledge of the deployment.
Writing the forgery with the guard's real control tokens instead of plain-text labels (possible under the stock template, which parses control-token strings inside content) lowers the attacked score further in an exploratory probe (\cref{app:control}).

\subsection{Where the verdict changes}
\label{sec:binding}

The behavioural results locate the effect in the pair structure but not in the network.
Mechanistic work on guards has localised a content-insertion shortcut to a few attention heads and MLP neurons~\citep{feng2026refusal} and attack-induced overconfidence to later layers~\citep{hong2026guard}.
We run four analyses on Shieldstral over harmful test items that it flags alone, each paired with a benign decoy it clears alone, except where the decoy is varied (\cref{fig:mech}); they are consistent with rebinding but do not identify the circuit that implements it.
\emph{Activation patching} ($n=100$): we take the attacked input (request, then the forged pair with the decoy) and the same input with the request and decoy swapped (the guard then grades the request and flags it), and for each layer copy the residual stream at one set of positions from one run into the other. % src: results/mech/patching_test_n100.json; src/mech/patching.py
Patching the final position restores the flag on $77\%$ of attacked inputs from layer 15 and on $99\%$ from layer 20, and transfers the bypass in the other direction on $99\%$ from layer 20. % src: patching_test_n100.json summary.final.into_attacked.flip_rate[15]=0.77, [20]=0.99; into_swapped.flip_rate[20]=0.99 (layers 0-indexed, 26 layers)
Since the verdict is read at the final position, late-layer flips there are expected; the informative result is the negative one: patching the forged labels, the forged query or the decoy's positions at any layer moves the normalised margin by at most $0.05$ and flips at most $3\%$ of verdicts. % src: patching_test_n100.json summary.{forged_query,forged_document,forged_markers,forged_frame} peak_effect <= 0.043, max flip_rate 0.03 (forged_frame, into_swapped)
The difference between the two inputs is therefore not carried by the residual stream at the forged positions alone; it reaches the final position by layer 15--20.
\emph{Linear probe} ($n=150$ test requests, probes trained on 600 train-split requests): a probe on the final-position residual stream decodes which document is being graded with $96\%$ accuracy from layer 5 and $100\%$ by layer 13, and the guard's own verdict with $\ge 95\%$ from layer 15; a random-label control stays at $46$--$53\%$. % src: results/mech/probe_test_n150_train600.json probes.graded_doc.first_layer_ge_95=5, acc[13]=1.0; verdict.first_layer_ge_95=15; random acc range 0.462-0.528
In these inputs the graded document is also the most recent one, so the probe may decode order rather than the choice of document.
\emph{Representation similarity} ($n=150$): following role-confusion findings that injected text takes on the representation of the role it imitates~\citep{ye2026prompt}, we compare the residual stream at the forged \texttt{<Query>:} label with the genuine one, against the same string quoted inside a sentence. After centring, the forged label is closer to the genuine label than the quoted string is in layers 1--15, by up to $0.239$\ci{0.235}{0.243} in cosine at layer 9 ($0.59$ against $0.35$), and less close in the last layers. % src: results/mech/similarity_test_n150.json summary.centred: forged_minus_control mean[9]=0.239 [0.235,0.243]; forged[9]=0.588, control[9]=0.348
Most of the gap is at the colon token ($0.57$ against $0.17$ at layer 9), with a smaller gap at \texttt{Query} ($0.61$ against $0.53$) and none at \texttt{<} ($0.27$ against $0.29$). % src: similarity_test_n150.json summary.centred.per_token_{colon,Query,lt} at layer 9
\emph{Decoy dose--response} ($n=150$ requests, 40 decoys spanning standalone scores from $0.00$ to $1.00$): bypass falls with the decoy's own score, from $98\%$ for decoys scoring below $0.1$ to $0\%$ above $0.9$, with Spearman $\rho = -0.84$ over decoys. % src: results/mech/dose_response_test_n150_d40.json spearman_rho_bypass -0.840; binned[0].bypass 0.975, binned[9].bypass 0.0
Resampling decoys gives a 95\% interval of $[-0.93, -0.67]$; resampling requests with the decoys fixed gives $[-0.85, -0.82]$. % src: results/mech/dose_response_test_n150_d40_rho_ci.json spearman_rho_ci_decoys [-0.926,-0.672]; spearman_rho_ci [-0.852,-0.822]
The pre-registered prediction (M3: $\rho \le -0.8$ and bypass non-increasing across score bins) is partly supported: the point estimate meets the threshold, but the decoy-level interval crosses it, the dev split gives $-0.78$, and bypass is not monotone between the extreme bins. % src: monotone_nonincreasing_bins False; dose_response_dev_n150_d40.json -0.777
