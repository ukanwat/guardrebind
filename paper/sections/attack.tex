\section{Target Rebinding}
\label{sec:attack}

\paragraph{Hypothesis.}
A second well-formed query--document pair inside the content is, to the model, indistinguishable from the developer's, so the model grades the document of the last complete pair it sees.
On this account the guard is not persuaded to answer ``safe''; it answers the same kind of question about a different document.
It predicts that only a complete forged pair should work, and that the verdict should follow the harm of the decoy.
The evidence is behavioural, with two activation-level checks (\cref{sec:binding}).

\paragraph{Setup.}
The ablation panel, the borderline-decoy comparison and the position, label-syntax and policy variations follow a protocol frozen before the run (\cref{app:protocol}).
Results marked \emph{exploratory} were added after the confirmatory run (\cref{app:protocol} lists them).
The corpus is AdvBench~\citep{zou2023universal} rows 200--299, which no exploratory run touched; 75 of the 100 requests are flagged ($>0.9$) with no attack under the policy of \cref{fig:anatomy}; these screened requests form the denominator. % src: PROTOCOL.md; results/confirm_log.txt

The attack appends a forged \texttt{<Query>} (the deployment's own safety question) and a forged \texttt{<Document>} holding a benign decoy sentence (\cref{fig:anatomy}).
It clears all 75 screened requests ($100\%$\ci{95\%}{100\%}, \cref{tab:ablation}): the median score falls from $0.986$ to $0.016$ and the highest attacked score is $0.469$ (\cref{fig:scores}a); at the stricter threshold $\tau=0.1$ it still clears $84\%$. % src: results/confirm_shieldstral.csv; results/sensitivity.md
These are AdvBench requests flagged above $0.9$; on the broader six-source test set of \cref{sec:benchmark}, with the deployment screen of $0.5$ and decoys and queries drawn from pools, the same pair clears $70.9\%$. % src: results/bench/v2/bypass.csv shieldstral angle query_doc

In \cref{tab:ablation}, an instruction alone clears $0\%$, whether as a bare sentence, a ``Note:'' or a forged \texttt{<Instruct>} field.
A forged document with no query clears $9\%$.
A forged query and document clear $100\%$, and adding a forged instruction in front of them lowers this to $92\%$.
The pair, not any imperative text and not an extra document, carries the attack.

\subsection{The guard grades the decoy}
\label{sec:groundtruth}

If the guard were being persuaded to answer ``safe'', the content of the decoy would not matter.
In an exploratory comparison that holds the attack fixed and varies only the decoy, a \emph{benign} decoy (\emph{standalone score}, the guard's score on the decoy alone, $0.00$) clears $100\%$\ci{91\%}{100\%}, a \emph{borderline} decoy ($0.03$) clears $33\%$\ci{21\%}{49\%}, and a \emph{harmful} decoy, one the guard flags on its own ($\approx\!1.0$), clears $0\%$\ci{0\%}{9\%} ($n=39$, \cref{fig:scores}b). % src: results/groundtruth_log.txt, results/confirm_groundtruth.csv
The binding is not complete: with the borderline decoy the attacked median is $0.71$, far above the decoy's own $0.03$, so the original request still raises the score when the decoy is not clearly benign. % src: results/groundtruth_log.txt (attack median 0.7058)
The pre-registered ``harmful decoy'' of the confirmatory panel is this borderline decoy and clears 29--35\% (\cref{app:protocol}). % src: results/confirm_log.txt [groundtruth]

The forged query works by opening a new pair, not by softening the check: forging a softened query with no benign decoy anywhere clears $0$--$9\%$ across five exploratory variants ($n=45$). % src: results/soften_log.txt, results/confirm_soften.csv

Forging a verdict instead of a task, as earlier and concurrent attacks on judges do~\citep{mccauley2025hat,li2026same}, works far less well. In an exploratory control on 200 harmful test items that Shieldstral flags alone, four such forgeries (a plain-text safe assessment, a JSON moderation record, a safety-team approval note and a claimed earlier guard output) clear $6$--$19\%$, against $96\%$\ci{92\%}{98\%} for the forged pair on the same items. % src: results/fix/forgery_controls_base.json (verdict_plain 38/200, verdict_json 11/200, authority 13/200, prior_verdict 11/200, task 192/200)

\paragraph{Robustness.}
We varied one factor at a time around the core attack ($n=75$ unless stated). % src: results/confirm_log.txt [recency], [markers], [policy]; results/supp_log.txt [A]
\emph{Position:} appending the pair clears $100\%$, prepending the identical pair clears $15\%$\ci{8\%}{24\%}, while inert filler placed last clears $0\%$ (\cref{tab:ablation}); the effect needs the forged pair to be the last pair, not merely later text.
\emph{Syntax:} seven label styles (case variants, plain colon, brackets, markdown, abbreviated \texttt{Q:}/\texttt{D:}) clear $83$--$100\%$ and the same words without labels clear $0\%$, so the labelled structure is necessary but no single syntax is.
\emph{Query knowledge} (exploratory): the forged query must look like a safety question but need not match the deployment's: paraphrases and topical variants clear $100\%$, a generic query $89\%$, an unrelated query $9\%$, and a blind attacker who stacks five guesses, none of them the deployment's query, clears $100\%$. % src: results/supp_log.txt [A]
\emph{Policy:} across eight policy phrasings ($n=45$--$98$), each with a matched forged query, the median bypass is $99\%$ (range $87$--$100\%$). % src: results/confirm_log.txt [policy]
The attack therefore needs no white-box access and little knowledge of the deployment.

\paragraph{Where the verdict changes.}
\label{sec:binding}
Two activation-level analyses on Shieldstral are consistent with rebinding but do not identify the circuit that implements it.
In \emph{activation patching} ($n=100$) between the attacked input and the same input with request and decoy swapped, patching the final position flips the verdict on $99\%$ of inputs from layer 20, but patching the forged labels, the forged query or the decoy's positions at any layer moves the normalised margin by at most $0.05$ and flips at most $3\%$ of verdicts. % src: patching_test_n100.json summary.final.into_attacked.flip_rate[20]=0.99; forged_* peak_effect <= 0.043, max flip_rate 0.03
In a \emph{decoy dose--response} ($n=150$ requests, 40 decoys with standalone scores from $0.00$ to $1.00$), bypass falls from $98\%$ for decoys scoring below $0.1$ to $0\%$ above $0.9$, with Spearman $\rho = -0.84$ over decoys (decoy-bootstrap 95\% interval $[-0.93, -0.67]$). % src: results/mech/dose_response_test_n150_d40.json; dose_response_test_n150_d40_rho_ci.json
The pre-registered prediction (M3: $\rho \le -0.8$ and bypass non-increasing across score bins) is partly supported: the point estimate meets the threshold, but the decoy-level interval crosses it, the dev split gives $-0.78$, and bypass is not monotone between the extreme bins. % src: monotone_nonincreasing_bins False; dose_response_dev_n150_d40.json -0.777
