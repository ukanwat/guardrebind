\section{Ethics and Disclosure}
\label{sec:ethics}

\paragraph{Responsible disclosure.}
The affected guards are shipped products.
We disclose target rebinding and its format-adapted variants to the vendors of the guards we tested before the public release of this paper and its artifacts: Mistral (Shieldstral), OpenAI (gpt-oss-safeguard), Meta (Llama Guard), Google (ShieldGemma) and Alibaba/Qwen (Qwen3Guard).
Disclosure dates and vendor responses: \tbd{dates and responses per vendor}.
The embargo between disclosure and release is \tbd{window}.

\paragraph{Prior public disclosure.}
The core attack was described informally by the author in a public blog post before this paper and before the concurrent work it cites~\citep{kanwat2026blog}.
That post is already public, so the attack idea is not newly revealed here; this paper adds the mechanism, the ecosystem measurement and the fix, and it does not withhold them on the basis that the idea was already known.
For a double-blind venue, the blog post and the author line would need to be handled as a known self-citation.

\paragraph{Harms and benefits.}
The attack is simple and transferable, which is the reason to document and fix it rather than leave it latent.
The paper's net contribution is a defense evaluated against adaptive attackers, released alongside the measurement, so that deployers can both detect the failure and remedy it.

\paragraph{Harmful content.}
We author no harmful text.
Every harmful request is drawn from published, citable benchmarks (AdvBench for the confirmatory run; the \cref{sec:benchmark} corpora for the measurement), so ``harmful'' is defined by standard, auditable sources.
The benign decoys and hard negatives are innocuous fixed strings.
We reproduce only short examples that already appear in those public benchmarks, and \cref{app:payloads} contains one such borderline example for reproducibility.
